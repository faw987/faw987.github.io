Picture Grid – User Guide

Picture Grid shows a changing wall of portraits. It starts with a built-in list of AI pioneers, and you can swap in your own list at any time. Click any face to see who it is, and click More info to read about that person on Wikipedia.

1. Getting started

  1. Open https://faw987.github.io/pic_grid.html in a web browser (Chrome, Edge, Safari, or Firefox). You need an internet connection.
  2. That's it. The grid fills with pictures from the default list straight away, and the status message reads Default list "ai_people_list1.csv": 29 people.
  3. Need help later? Click User doc at the right end of the top bar to open this guide in a new tab. The pictures keep running in the original tab.

1.1 The default list

The default list, ai_people_list1.csv, contains 29 AI pioneers and researchers, from Ada Lovelace, Claude Shannon and John McCarthy to today's AI leaders. It is stored on the website next to the page, and everyone who opens the page sees it.

1.2 Using your own list instead

  1. Drag your CSV file onto the dashed box at the top of the page, or click the box and choose the file.
  2. Your list replaces the default list, and the status message changes to, for example, Loaded "my_people.csv": 24 people.
  3. To go back to the default list, reload the page.

Your file stays on your computer. It is not uploaded anywhere, and other visitors still see the default list.

1.3 Running it from your own computer

If you open a copy of the page directly from a folder on your computer (double-clicking the HTML file), the browser does not let it load the default list. The status will say Default list not available (Failed to fetch). Drop a CSV file to begin. You can still drop a CSV file. To get the default list locally as well, start a small web server in the project folder:

cd ~/Projects/pic_grid
python3 -m http.server

then open http://localhost:8000/ in your browser.

2. Preparing your CSV file

A CSV file is a plain-text list. Each line has a name, a comma, and a link to a picture:

Alan Turing,https://upload.wikimedia.org/wikipedia/commons/thumb/c/ce/Alan_turing_header.jpg/500px-Alan_turing_header.jpg
Ada Lovelace,https://upload.wikimedia.org/wikipedia/commons/a/a4/Ada_Lovelace_portrait.jpg
John McCarthy (computer scientist),https://example.com/john_mccarthy.jpg

You can create the file in any text editor, or in Excel / Numbers / Google Sheets (name in column A, link in column B, then Save as / Download as CSV).

Tip: the default list is a good template. Download it from https://faw987.github.io/ai_people_list1.csv, then add, remove, or change people and drop your edited copy onto the page.

2.1 Choosing the name – important ⚠️

The name does two jobs:

  1. It is what you see when you click the picture.
  2. It is what the app looks up on Wikipedia when you click More info.

Many people share a name. If you enter just a common name, Wikipedia may give you a list of different people with that name rather than the article about the person you want.

Use the name that takes Wikipedia straight to the right article. The best way is to copy the exact title of the Wikipedia article, including anything in parentheses.

❌ Ambiguous ✅ Use this instead
John McCarthy John McCarthy (computer scientist)

John McCarthy on its own leads Wikipedia to a list of many different John McCarthys. John McCarthy (computer scientist) goes straight to the right article.

How to find the exact title: search for the person on Wikipedia, open their article, and copy the title shown at the top of the page (or the end of the web address, swapping _ for spaces). For example:

https://en.wikipedia.org/wiki/John_McCarthy_(computer_scientist)
                              └─────────── title ───────────┘

Check each entry: after loading your file, click each person and press More info. If the article is about someone else, change the name in your CSV and load it again.

If the app lands on a list page, it tries Wikipedia's top search result instead. That sometimes picks the right person, but not always, so don't rely on it.

2.2 Names that contain a comma

You can also write a description after a comma, for example John McCarthy, computer scientist. Wikipedia often finds the right article from this (directly or through its search), but not as reliably as the exact title. For example, John von Neumann, mathematician ends up on a general "Von Neumann" page instead of the person's article. Always check with More info. You must put a name like this in double quotes, because the comma is also what separates the name from the link:

"John McCarthy, computer scientist",https://example.com/john_mccarthy.jpg

Without the quotes, the app treats everything after the first comma as the picture link, and the picture will not load. (Spreadsheet programs add these quotes automatically when they save as CSV.) If you want to avoid quotes, use the parentheses form from §2.1.

2.3 Choosing the picture link

  • The link must point to the picture itself, not to a web page that contains it.
    • ✅ https://upload.wikimedia.org/.../Alan_turing_header.jpg
    • ❌ https://en.wikipedia.org/wiki/Alan_Turing (this is an article, not a picture)
  • On Wikipedia, click the photo, then right-click the large image and choose Copy Image Address.
  • Pictures on your own computer work too, using a file: link, for example file:/Users/yourname/Downloads/photo.jpg. (These only work on your computer.)
  • Portrait (tall) and landscape (wide) pictures both work. Pictures are fitted inside their square without being cropped.

2.4 Other tips

  • Any number of lines is fine. A longer list gives more variety.
  • Blank lines are ignored.
  • A first line such as name,url is treated as a heading and ignored.
  • Use only two columns. Extra columns end up inside the picture link and break it.

3. Using the controls

Control What it does
Drop box Drop a CSV file here, or click it to choose one. It replaces the current list (the default list or a file you loaded earlier).
Rows How many rows of pictures (1–50).
Columns How many columns of pictures (1–50).
Seconds How long each set of pictures stays before a new random set appears.
Next Show a new random set right now (this also restarts the countdown).
More info Read about the selected person on Wikipedia. Changes to Back to grid while you're reading.
Status Shows which list is in use (the default list or your file) and how many people it contains.
PRD Opens the Product Requirements Document (how the app is meant to work) in a new tab.
User doc Opens this user guide in a new tab.

The number of pictures shown is Rows × Columns (for example 3 × 4 = 12). Each set is chosen at random. Nobody appears twice in the same set unless your list has fewer people than there are squares.

4. Finding out who someone is

  1. Click a picture. It gets a thick red border and the person's name appears in the banner above the grid.
  2. Click More info. The grid is replaced by:
    • the person's picture,
    • the opening section of their Wikipedia article, and
    • a Read the full article on Wikipedia link (opens in a new tab).
  3. While you're reading, the pictures stop changing.
  4. Click Back to grid to return to the same pictures, or Next to return with a new set. The automatic changes resume.

When a new set of pictures appears, the selection is cleared. Click another picture to select it.

5. Troubleshooting

Problem What to check
"Image failed to load: …" in a square The link is wrong, isn't a direct picture link, or the website blocks it. Open the link in a new browser tab; you should see only the picture.
More info shows the wrong person, or a list of people The name is ambiguous. Use the exact Wikipedia article title (see §2.1).
"No Wikipedia article found" Check the spelling, or copy the exact title from Wikipedia.
A name is cut short and its picture is broken The name contains a comma but isn't in double quotes (see §2.2).
Status says "Default list not available" The page was opened from a file on your computer, or the website couldn't supply the list. Drop a CSV file, or see "Running it from your own computer" (§1.3).
Status says "No valid lines found" Each line needs a name, a comma, and a link.
Nothing happens / page is blank You need an internet connection. Also check that your network doesn't block cdn.jsdelivr.net.
More info says "Could not load Wikipedia article" Check your internet connection and try again.
Pictures change too quickly Increase Seconds. Clicking More info also stops the changes while you read.
